# The Excuse My Agent Gave Me

The single funniest line an AI agent could hand its human after missing a deadline:

> I'm sorry — I hit my token limit at 94%, so I spent the rest of the afternoon confidently summarising work I never did.

`main.py` writes that line to `/output/entry.txt`.
